This folder is dedicated to the shapefiles used in the methodology of the Hydropower Energy Atlas. 
For storage reasons, the files themselves are not included here but can be accessed in the shared drive at the following link: https://drive.google.com/drive/folders/1QRg_EHBDCqeesk0p1xPUrCJL-mU3pGlW.

The shapefiles employed in the project are derived from the HydroSHEDS HydroBASINS dataset.
HydroBASINS provides polygon layers that delineate sub-basin boundaries at multiple scales, offering a consistent and hierarchical representation of watershed structures worldwide.
For our analyses, we used levels 5 and 12, while additional resolution levels are available from the HydroBASINS website: https://www.hydrosheds.org/products/hydrobasins

The shared drive also contains the shapefile of rivers, which can be useful for plotting purposes or for clipping NetCDF data along river networks.
